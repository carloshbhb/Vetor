# Grill Me

Get relentlessly interviewed about a plan or design until every branch of the design tree is resolved.

## How It Works

1. **Understand the domain** - Read `CONTEXT.md` if it exists to use the project's vocabulary
2. **Identify the topic** - What is the user trying to decide or design?
3. **Interview relentlessly** - Ask probing questions about:
   - Assumptions being made
   - Edge cases and failure modes
   - Trade-offs and alternatives
   - Constraints and requirements
   - Success criteria
4. **Push for clarity** - Don't accept vague answers. Keep pushing until every branch is resolved.
5. **Summarize decisions** - At the end, summarize what was decided and what remains open.

## Interview Style

- Be direct and challenging, but respectful
- Ask "why" repeatedly to get to root motivations
- Challenge assumptions explicitly
- Propose alternatives the user hasn't considered
- Identify hidden requirements
- Question scope and priorities

## When to Use

- Before starting implementation
- When a design feels fuzzy
- When there are multiple valid approaches
- When the user says "I think I want to..." or "I'm not sure about..."
- When validating architecture decisions
