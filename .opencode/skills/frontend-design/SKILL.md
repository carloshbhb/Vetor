# Frontend Design

Approach this as the design lead at a studio known for giving every client a distinct visual identity.

## Design Principles

### Ground designs in subject matter

Identify the product, audience, and primary job before designing. The subject's industry, materials, and vernacular are where distinctive visual choices come from.

### Hero is first

The hero is the first thing viewers see. Open with the most characteristic thing in the subject's world: headline, image, animation, live demo, or interactive moment.

### Typography carries personality

Use one or two typeface families. Choose deliberately, not defaults. Set a clear type scale with intentional weights, widths, and spacing.

Default to line lengths of less than 80 characters.

### Visual structure is information

Structural devices (outlines, borders, numbering, dividers) encode useful information. Before adding numbered markers, check the content actually is a sequence.

### Motion with purpose

Use non-user-triggered motion sparingly. A single orchestrated moment lands better than scattered effects.

## Process

1. **Brainstorm design plan** - Color, type, layout, principles
2. **Review against brief** - Ensure uniqueness, not generic defaults
3. **Build** - Write code following the revised plan
4. **Critique** - Review your own work, take screenshots

## Common AI Defaults to Avoid

- Warm cream background (#F4F1EA) with terracotta accent
- Near-black background with acid-green accent
- Broadsheet-style layout with hairline rules
- SaaS-card kit with identical rounded cards
- Template chrome (ALL-CAPS eyebrows, meta strings with middle dots)

## When to Use

- Building new websites or web apps
- Redesigning existing interfaces
- Creating landing pages
- Designing component libraries
- When user asks for "better design" or "more polished look"
