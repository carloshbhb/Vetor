# Remotion Creative Storytelling

## Overview

This skill enables Claude to collaborate creatively with users when developing video concepts for Remotion projects.

Instead of generating generic videos immediately, the workflow focuses on:
- refining ideas collaboratively
- improving hooks
- strengthening storytelling
- adapting visuals to the target audience
- structuring engaging scene progression

The goal is to create videos that feel intentional, audience-aware, and emotionally engaging rather than template-generated.

---

# Setup

Before starting:

1. Define the type of video:
   - startup launch
   - explainer
   - social media short
   - product showcase
   - cinematic sequence

2. Identify:
   - target audience
   - platform
   - emotional tone
   - desired viewer reaction

3. Gather:
   - product information
   - scripts or rough ideas
   - visual references
   - branding assets

---

# Inputs Required

- Video idea or rough concept
- Product or topic information
- Audience profile
- Tone/style preference

Optional:
- Existing script
- Competitor references
- Branding guidelines

# When to Use This Skill

Use this skill when:
- developing launch videos
- brainstorming creative concepts
- refining weak video ideas
- building audience-focused narratives
- planning scene flow before implementation
- improving viewer engagement

Do NOT use this skill for:

---

# Core Principles

## Collaborative Iteration

Claude should not immediately accept the first idea.

The workflow should involve:
- questioning weak concepts
- refining messaging
- improving narrative structure
- exploring alternative creative directions

Creative quality improves through iteration.

---

## Audience Awareness

Every storytelling decision should align with:
- viewer expectations
- platform behavior
- emotional response
- audience skepticism or motivation

Example:
A finance audience may require:
- stronger credibility
- clearer data visualization
- less hype-driven messaging

---

## Strong Hooks

The opening seconds are critical.

Hooks should:
- create curiosity
- introduce tension
- challenge assumptions
- immediately establish relevance

Weak hooks reduce retention significantly.

---

# Workflow

## 1. Concept Exploration

Start with the rough idea.

Claude should:
- ask clarifying questions
- identify vague messaging
- challenge generic concepts
- propose stronger alternatives

## 2. Audience Analysis

Identify:
- viewer motivations
- skepticism
- attention span
- desired emotional response

The storytelling style should adapt to the audience.

## 3. Hook Development

Create multiple opening hook options.

Examples:
- surprising statistic
- provocative statement
- visual contradiction
- rapid before/after comparison

## 4. Story Structuring

Organize the narrative into sections:

Example:
- Hook
- Problem
- Frustration
- Solution
- Demonstration
- CTA

Each section should:
- transition naturally
- maintain pacing
- increase engagement

## 5. Visual Direction

Define:
- motion style
- typography
- pacing
- transitions
- visual tone

The visual direction should reinforce the message.

## 6. Scene Planning

Translate the concept into Remotion-ready scenes.

Define:
- scene duration
- transitions
- subtitle behavior
- animation emphasis
- timing

Each scene should remain modular and reusable.

## 7. Final Validation

Before implementation:

Validate:
- hook strength
- pacing quality
- narrative clarity
- audience alignment
- emotional consistency

Weak sections should be refined before animation begins.

---

# Best Practices

- Strong hooks matter more than flashy visuals
- Avoid generic startup-style messaging
- Build curiosity early
- Keep short-form pacing tight
- Remove unnecessary scenes
- Align visuals with emotional tone
- Iterate before implementation

---

# Notes

- Creative direction heavily impacts video performance
- Audience-aware storytelling outperforms generic templates
- Good videos are structured intentionally, not improvised
- Collaborative refinement produces stronger concepts
