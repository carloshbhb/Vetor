## Modeling instruction

Create a clean, presentation-ready 3D model for product review video. Treat the attached product photos and official specifications as the only source of truth.

1. Match the exterior silhouette and proportions before adding fine details.
2. Use physically separate mesh objects for distinct visible parts that may need animation (for example body, lid, handle, cap, display, buttons).
3. Reproduce a logo, port, seam, button or texture only when it is visible in a reference image or explicitly specified.
4. Do not invent internal components, hidden mechanisms, technical claims, dimensions or accessories.
5. Do not add a generic brand mark or decorative feature that is absent from the real product.
6. Use neutral studio materials first; refine material roughness, metallic response, transparency and texture only when supported by the references.
7. Create named front, side, rear and detail camera views. Save the source .blend file.
8. Create a turntable preview and inspect the silhouette against the source photos before exporting.
