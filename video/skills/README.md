# Vetor video skills

These local agent skills turn the reference corpus into repeatable production practice.

| Skill | When to use |
|---|---|
| [Opus creative direction](./opus-creative-direction/SKILL.md) | Choose visual language, assets, storyboard and per-scene treatments. |
| [Opus motion graphics](./opus-motion-graphics/SKILL.md) | Implement deterministic Remotion, 2D, SVG, GSAP and Three.js animation. |
| [Independent video critic](./opus-video-critic/SKILL.md) | Review rendered outputs and issue REJECT / REVISE / PASS verdicts. |

## Operating rule

The skills are guidance for agents and creative planning, not a second renderer. They use the existing Remotion/Three.js/GSAP stack and preserve the production queue, Edge TTS, caption timing, FFmpeg muxing, QA and YouTube publishing controls.
