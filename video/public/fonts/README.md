# Fontes do vídeo

Arquivos locais para o render ser determinístico (sem baixar fontes do Google durante o render).

- `inter-latin-wght-normal.woff2` — Inter (variável, subset latin, cobre acentos do português). SIL OFL 1.1, ver `LICENSE-Inter.txt`.
- `space-grotesk-latin-wght-normal.woff2` — Space Grotesk (variável, subset latin). SIL OFL 1.1, ver `LICENSE-SpaceGrotesk.txt`.

Origem: pacotes npm `@fontsource-variable/inter` e `@fontsource-variable/space-grotesk`.
Carregadas por `src/styles/loadFonts.ts` via `@remotion/fonts`.
