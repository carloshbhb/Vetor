# Nexu Marketing Psychology Skill

Purpose: Design skills informed by marketing psychology principles for
compelling, conversion-focused interfaces following nexu-io/open-design
patterns.

## Psychological Principles

### 1. Color Psychology

| Color | Psychological Effect | UI Application |
|-------|----------------------|----------------|
| Red | Urgency, excitement, importance | Clear CTAs, error messages, sale badges |
| Blue | Trust, stability, professionalism | Corporate interfaces, navigation, links |
| Green | Growth, health, positivity | Success states, "Add to Cart", financial contexts |
| Yellow | Attention, optimism, warning | Highlights, caution areas, accent notes |
| Purple | Luxury, creativity, premium | Premium brands, creative interfaces, differentiate |
| Orange | Friendliness, confidence, call-to-action | Secondary buttons, interactive elements |

### 2. Typography Psychology

- **Serif fonts** (Playfair Display, Georgia): Convey tradition, reliability, luxury. Best for headings
- **Sans-serif fonts** (Arial, Helvetica, Geist Sans): Convey modernity, accessibility, efficiency. Best for body text
- **Monospace**: Conveys technical precision, code, developer-focused contexts

### 3. Social Proof Elements

- **Testimonials with photos**: Increase credibility by 40-70%
- **User counts** ("1,000+ happy customers"): Create bandwagon effect
- **Expert endorsements**: Transfer authority and trust
- **Badges and certifications**: Validate quality at a glance

### 4. Scarcity & Urgency

- **Limited time offers**: Create FOMO (fear of missing out)
- **Low stock indicators**: "Only 3 left in stock"
- **Countdown timers**: Direct urgency with visual countdown
- **Exclusive access**: "Invite-only" creates perceived value

### 5. Fogg Behavior Model

Behavior = Motivation × Ability × Trigger

- **High motivation + high ability + trigger** = Immediate action
- **Reduce ability friction** when motivation is low
- **Use triggers** strategically (not deceptively)

## UI Pattern Applications

### Conversion-Optimized CTAs

| Pattern | Psychology Principle | Implementation |
|---------|---------------------|----------------|
| "Limited time" button | Scarcity + urgency | Red accent + countdown text |
| "Join 1,000+ users" | Social proof | Large number + green accent |
| "Free trial - no credit card" | Reduced friction | Remove barrier trigger |
- Personalized messaging based on user behavior

### Trust-Building Patterns

| Pattern | Psychology Principle | Implementation |
|---------|----------------------|----------------|
| Secure badges | Authority & trust | Top-right corner, small but visible |
| Money-back guarantee | Risk reduction | Below pricing, clear text |
| Privacy policy link | Transparency | Footer, unobtrusive |
- Context-appropriate testimonials

### Friction-Reduction Patterns

| Pattern | Psychology Principle | Implementation |
|---------|----------------------|----------------|
| Progress indicators | Ability perception | Multi-step forms, show progress |
- Auto-fill saved data
- Smart default selections

## Best Practices

1. **Use color psychology strategically** - align colors with desired user emotion/action
2. **Leverage social proof authentically** - never fabricate user counts or testimonials
3. **Balance scarcity with honesty** - don't create false urgency
4. **Reduce friction without reducing value** - make action easy while maintaining purpose
5. **Apply Fogg model holistically** - consider motivation, ability, and triggers together
6. **Test and iterate** - A/B test psychological patterns for your specific audience
7. **Respect user autonomy** - psychological techniques should guide, not manipulate
